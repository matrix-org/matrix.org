- Hosted Synapse homeservers, set up in one click from a [template](https://pethost.dev/templates/synapse/)
- PostgreSQL, HTTPS and federation on port 443 included
- Nightly backups, SSH into the containers and request logs

Pethost runs Synapse with PostgreSQL on a machine it hosts for you, from €9.99 a month. The admin account is made from the username and password you give at setup, and other people sign up with the server's registration token. The server name is the project's address under `pethost.app`. The same machine can also run bridges, bots or other apps, at no extra cost.
