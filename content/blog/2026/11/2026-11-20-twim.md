>

> - Invite filtering (MSC4155) and invite reasons in `createRoom` (MSC4491)
> - Profile updates in `/sync` (MSC4429)
> - Remote toggling of push notifications (MSC3881), and push rules for polls and encrypted events (MSC3930, MSC4028)

> 
> - Sliding sync on `/v4/sync`, with the accepted extensions and the MSC4551 receipt rules
> - Batch profile lookups (MSC4536) and whole-profile replacement (MSC4437)
> - Redacting all of a user's events in a room (MSC4194)
> - Ringing for MatrixRTC call notifications (MSC4075) and the stable `rtc/transports` endpoint (MSC4143)
> - To-device events and key queries for application services (MSC4203, MSC3983, MSC3984)

## Dept of Clients 📱

### WizardChat ([website](https://wizardchat.org))

[j20a05n](https://matrix.to/#/@j20a05n:matrix.org) reports

> Hi TWIM! We'd like to introduce WizardChat, an open-source, end-to-end encrypted Matrix client built for communities that want to leave Discord without giving up voice rooms, screen sharing or soundboards. It runs on the web, on Windows, macOS and Linux, and as native apps on iOS and Android.
> 
> Every app shares one Rust core built on matrix-rust-sdk. It's compiled to WASM for the web, wrapped with Tauri on desktop, and bound through UniFFI to SwiftUI and Jetpack Compose on mobile. Calls use MatrixRTC with LiveKit, with push to talk everywhere (system-wide on desktop), screen sharing with system audio, and an experimental on-device noise filter based on RNNoise. In calls there's also a soundboard (MSC4577) with custom sound packs, and Watch Together for YouTube with a shared queue, both synced over the call's data channel. Beyond calls, there are custom emoji and sticker packs, pronouns and a different name in each room or space, a theme editor, and QR and OAuth login.
> 
> Try it in your [browser](https://app.wizardchat.org) or grab an app from the [downloads](https://wizardchat.org/download). Android is on F-Droid and Obtainium, with a Google Play beta running, and iOS can be sideloaded while the App Store review is pending. You can find the source code on [GitLab.](https://gitlab.com/wizardchat/wizardchat)
  
### Element X iOS ([website](https://github.com/vector-im/element-x-ios))

A total rewrite of Element iOS using the Matrix Rust SDK underneath and targeting devices running iOS 17+.

[Doug](https://matrix.to/#/@douge:matrix.org) says

> Exciting news for iOS users this week as our multi-account support is starting to take shape! Much of the underlying code has been made account-aware, and the Settings screen has received the new component for switching accounts, so we’ve wired up the add account flow under a feature flag for the first time. It’s still very much a work in progress as there are many flows to review and update before it’s fully ready, but it’s great to see it working after *lots* of refactoring. Other notable changes to report include:
> 
> - Call screens are now presented independently of the user session screens, meaning you’ll be able to join a call for account A and use a PiP whilst checking messages in account B.
> - Recovery and verification flows have had a general tidy-up to make them more helpful and consistent with the other Element clients.
> - We’ve been experimenting with particle effects on reactions and now support the rendering of `data-mx-emoticon` images in both reactions and message bubbles.
> - In the timeline, date separators are now exposed as headings to VoiceOver, making it quick to navigate between days. The loading indicator also no longer flickers in between pagination requests.
> - We’ve updated CI to use Xcode 27.2, meaning we can now start to tweak the layout on iPhone Duo. We’ve been building for the Duo since launch but needed the CI changes to actually use the new APIs.

>
> Tammy now renders custom image reactions cleanly (no raw `mxc://` URLs anymore)! ### botanica ([website](https://botanica.starlightnet.work))

[soweli leia](https://matrix.to/#/@me:cyrneko.eu) reports

> announcing 0.0.2-alpha of botanica!
> 
> botanica is a small, fedora-based OS that I’ve been slowly chipping away on, which’s end-goal is to make it easier to self-host matrix at home by taking out the work of finding the right software, setting it up yourself, and maintaining the system.
> 
> it builds on fedora-bootc, so you get atomic updates, rollbacks, and the ability to switch to another image at any time, or extend it!
> 
> it’s still very, very work-in-progress, many things are still unimplemented or don’t work quite right, but the basics to configure continuwuity and sable are there, and with a bit of manual work getting it connected to the wider internet, [it can federate!](https://connectivity-tester.mtrnord.blog/results/p/1Q_znIM3YQ-6)
> 
> it comes with a small TUI written in python+textual, called `flower`. it’s aim is to make first-time-setup easier while also providing basic system utilities, like doing updates or checking on the status of various system services.
> 
> and finally, it’s in *desperate* need of more than one person working on it 😵‍💫; but I’m hopeful that’ll change over time!
> 
> you can find more about it at <https://botanica.starlightnet.work>, and source code at <https://forge.starlightnet.work/Team/botanica>; The project is [AI:0](https://0rwx.com/)
