### policyserv ([website](https://github.com/matrix-org/policyserv))

A proactive safety and moderation tool for Matrix communities.

[TravisR](https://matrix.to/#/@travis:t2l.io) reports
 
> PolicyServ [v1.8.0](https://github.com/matrix-org/policyserv/releases/tag/v1.8.0) has been released! Aside from the plethora of dependency updates, this release primarily contains a refactor to use [MSC4456 harms taxonomy](https://github.com/matrix-org/matrix-spec-proposals/pull/4456) internally. By using the harms taxonomy, we're able to more clearly communicate *why* an event wasn't allowed in a room via [MSC4387's `M_SAFETY` error code](https://github.com/matrix-org/matrix-spec-proposals/pull/4387) (when client support follows). 
> 
> The refactor may have changed how some filters behave or work. We encourage using a staging environment where possible, though it's safe to roll back to v1.7.0 if something goes wrong. Let us know if you run into any bugs in [#policyserv:matrix.org](https://matrix.to/#/#policyserv:matrix.org). 
> 
> The [Foundation's policyserv instance](https://github.com/matrix-org/policyserv-setup-bot#usage) is available to communities, and has been running the release over the weekend.

> - We've been busy this week addressing the onslaught of security advisories reported in our dependencies. As with any security issue, it's recommended to update as soon as you can!
> - Synapse now advertises support for Matrix v1.16 and v1.17 ([#20333](https://github.com/element-hq/synapse/pull/20333), [#20334](https://github.com/element-hq/synapse/pull/20334)).

> - Media uploads no longer leave behind orphaned files on disk when they exceed the `media_upload_limits` ([#20006](https://github.com/element-hq/synapse/pull/20006)).
> - A couple more Synapse Rustification updates including laying the foundation for a Rust-backed database pool ([#19996](https://github.com/element-hq/synapse/pull/19996)) and a clock source on the Rust side ([#20294](https://github.com/element-hq/synapse/pull/20294)).
> 
> Thank you to all our contributors for helping to make Synapse the best it can be. As always, feel free to stop by #synapse:matrix.org to join in on the discussion, and if you encounter a bug, make sure to [report it](https://github.com/element-hq/synapse/issues/new/choose).

[Dominik [m]](https://matrix.to/#/@dominik:fuchss.org) reports

> Back in April I [introduced Tacit here](https://matrix.org/blog/2026/04/24/this-week-in-matrix-2026-04-24/), my desktop-first Matrix client and fork of [Tammy](https://gitlab.com/connect2x/tammy). Since then it has grown from "works on my machine" into something you can actually download: the **first releases are out** 🎉 The current one is **26.9.2-tacit.7**.
> 
> You can grab builds for **macOS** (Apple Silicon), **Windows** and **Linux**, and the web version is available as a Docker image (`ghcr.io/dfuchss/tacit`). If you just want to try it without installing anything, there is a public web instance at <https://tacit.fuchss.org>. The version number tells you which Tammy release it is based on, so Tacit keeps following upstream and picks up new Tammy and trixnity-messenger features over time.
> 
> #### What's new since the first announcement
> 
> - **Guilds got categories**: spaces are still shown as guilds, but you can now group rooms into categories (subspaces), browse them and invite people to a whole guild or category
> - **A calmer timeline**: messages from the same sender are grouped, mentions get a soft highlight, and failed messages can be retried right where they are. New in 26.9.2-tacit.4: runs of room events (joins, invites, room settings, …) collapse into a single row like "6 room events by Alice and Bob" that expands on click, so a fresh chat no longer starts with a wall of notices

> Tacit is still **alpha** and still a weekend project for friends and me, so expect rough edges. The builds are not signed yet; the README explains how to start them anyway.

### Mactrix ([website](https://github.com/viktorstrate/mactrix))

[Viktor Strate](https://matrix.to/#/@viktorstrate:qpqp.dk) announces

> The [latest release of Mactrix](https://github.com/viktorstrate/mactrix/releases) (a native macOS Matrix client) contains a lot of new features that I have been working on over the last month's time. Here are the highlights:
> 
> - **Rewrite entire timeline in AppKit** The timeline view has been rewritten purely in AppKit without any SwiftUI components. This simplifies things compared to the previous hybrid implementation that required a lot of fragile bridging code. **This means that the new timeline is more capable, way faster, and more stable.** For instance, the timeline now groups consecutive messages from the same sender and collapses consecutive status updates.
> - **Attachment uploading** Attachments can now be added to messages by dragging or pasting files or media to the message composer. You can add several attachments to the same message. The attachments are sent together with the message text.
> - **Sidebar space grouping** Rooms and sub-spaces are now grouped into your top level spaces.
> - **Mentions** User mentions in messages now show as a visual colored pill with their avatar image next to it. You can now also mention users by writing an @ symbol to open an autocomplete popup with all users in the room.
> - **Message editing** Messages can now be edited directly in the the timeline, by pressing the new pencil icon from the action bar when hovering over the message.
> - **Better link handling in messages** When clicking <https://matrix.to> links, the app will now load the link directly inside the app instead of opening the web browser. Usernames in status messages can now also be clicked to open details about their profile.
> - **User drag and drop** The initial work for supporting general drag and drop has been implemented for users. You can now drag users from the timeline or the inspector. Currently, you can only drop them into the message composer to mention them, but in the future this could be extended to invite users to rooms or change their permissions.
> 
> If the project sounds interesting, come say hi in our room [#mactrix:qpqp.dk](https://matrix.to/#/%23mactrix:qpqp.dk)
